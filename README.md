# NexMarket

India-focused marketplace to buy and sell websites and Android apps.

## Categories

- Websites for Sale
- Android Apps for Sale

## Run locally

```bash
# Backend
cd backend
npm install
npm start

# Frontend
cd frontend
npm install
npm run dev
```

Frontend proxies `/api` to `http://localhost:3001`.
